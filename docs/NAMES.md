# 这五只到底叫什么 —— 名字考证

> **一句话结论（页游口径）**：传说五王 = **龙炎 / 诺亚 / 帝释天 / 修尔 / 阿瑞斯**。
> 你给的这五只，是这五王的**初始（幼年）形态**：**小炎 / 小诺 / 小天 / 阿修 / 阿瑞**。
> 你平时管暗王叫「阿修」—— 那不是俗称，**那就是官方名**。

这份文档是为了堵住「名字是不是你在这儿瞎想的」这个质疑：下面每个名字都带**页游官方链接**，
并且把「你给的素材」和「官方图鉴图」**逐张对照**过。早期我自取的代号
（霜狼 / 金瞳 / 翠灵 / 绯羽 / 赤角）已**全部替换**，仓库里零残留。

## 0. 两级名字：为什么一只宠物有两个名字

桌宠有**两套素材**（右键可切，见 [HIRES.md](HIRES.md)），它们是**同一批角色的两个形态**：

| | 帧素材 `frames`（默认之一） | 官方高清素材 `hires` |
|---|---|---|
| 形态 | **初始形态**（幼年） | **传说王者**（进化后） |
| 官方名 | 小炎 / 小诺 / 小天 / 阿修 / 阿瑞 | 龙炎 / 诺亚 / 帝释天 / 修尔 / 阿瑞斯 |
| 素材出处 | 页游图鉴图（与用户给的 sprite 同设计） | 页游图鉴立绘 370×344（官方高清） |
| 桌宠里显示的名字 | 用**五王本名**（角色身份），初始形态名作为别名与说明 | 同左 |

所以菜单里写的是 `龙炎（初始形态 小炎 · huo）` 这种形式：**角色本名 + 初始形态名 + id**，
两边都不会误导。

* 手游官网：`aqsy.100bt.com`（**本插件不采用**；抓取过程中对 `aqsy`、`/aoqi/m/` 的匹配次数为 **0**）

## 2. 「传说五王」「小五王」都是官方用词

* 带「**传说五王合体**」tag 的精灵，整个精灵大全里**只有 1 条**：**极** —— 官方成长故事原文写着
  「……初心永在，**传说五王灵魂融合**……」
  官方图鉴：<http://aoqi.100bt.com/jingling/294876.html>
* 名字里带「**传说王者·**」的共 **6 条**：龙炎 / 诺亚 / 修尔 / 阿瑞斯 / 帝释天 **＋ 诺雅**。
  诺雅是**诺亚的妹妹**（「小诺雅」条目的标签原文就是「诺亚的妹妹」），**不属于五王**。
* 于是：**传说五王 = 龙炎、诺亚、修尔、阿瑞斯、帝释天**（正好五个）。
* 桌宠里没有诺雅，也没有合体体「极」—— 这两只都写在 `assets/pets/names.json` 的 `notIncluded` 里。
* 「**小五王**」（= 五王的初始形态合集）也确实是官方用词：官方资讯《小五王突破次元壁!》的横幅与头图里，
  五位传说王者与五只初始形态**同框**出现，配色与 `R.png` 的 金/木/水/火/暗 逐一对应：
  <https://img4.a0bi.com/upload/articleResource/20210303/1614754788311.png>（3673×666）、
  <https://img4.a0bi.com/upload/articleResource/20210303/1614754579160.png>（4582×2669）。
  **诚实标注**：这两张图挂在手游资讯域名下，本项目**只把它当成「用词有官方出处」的旁证**，
  手游素材一律没有进插件（第 1 节的口径不变）。
* 第三方旁证（不作为依据，仅记录）：4399 把这组叫「五王系列」；百度知道列的五王名单与上表一致。
  容易混淆的**不是**这五只：**五皇**（幻皇/元皇/界皇/冥皇/空皇）、**五召唤**（光明王/末炎/冰灵王/天蛮王/月影王）。

## 2.5 独立复核（两套方法、同一结论）

上面这套结论后来被**另一条完全独立的路**复核过一遍，结论一致：

1. **官方 CDN 直链**：官方《精灵大全》列表页每个条目的 `dsrc` 直接指向官方图鉴图，文件名就是精灵 id ——
   小炎 `resource.a0bi.com/aoqi/version3/resource/jingling/93496.png`(104×102 RGBA)、小诺 `57449.png`、
   小天 `76920.png`、阿修 `57451.png`、阿瑞 `93600.png`。这五张就是**初始形态官方能给到的最大原图**。
2. **卡面角标读属性**：官方图鉴卡片 575×273（角色本体只有 80–145px），4× 放大读角标得到
   超能/魔法（小诺）、恶魔/利爪（阿修）、战神/平衡（小炎）、草灵/肉盾（阿瑞）、光宠/射击（小天）。
   详情页的属性栏是 JS 渲染抓不到纯文本，所以属性以角标为准 —— 其中**只有小炎存疑**（角标是「战神/平衡」）。
3. **负向检查**：仓库早期的自造代号（霜狼 / 赤角 / 翠灵 / 绯羽 / 金瞳）在官方 **7068** 条精灵条目里
   **0 命中**，确认是编的，现已全仓库替换。

## 4. 怎么把名字对上图的（不是靠感觉）

1. 抓下页游「精灵大全」（列表页共 **3516** 个条目，去重后 **3512** 条精灵），拿到名称、详情页、缩略图。
2. 缩略图 **3512 张全部下载成功**（0 失败），对你的 5 张 sprite 做特征比对（颜色直方 + 轮廓 + 结构），
   每只取 **Top 60** 候选逐张看图排除，Top-1 分数：

   | id | Top-1 | 分数 | 被排除的相近候选（举例） |
   |---|---|---|---|
   | `huo` | 小炎 | 0.9262 | 蜘蛛小炎 / 拽小炎 / 远古小炎（小炎本体的**衍生形态**） |
   | `jin` | 小诺 | 0.8613 | 迷你诺 / 萌诺诺 / 生存专家·小诺（小诺族衍生萌宠） |
   | `an` | 阿修 | 0.8106 | 酷小修（皮肤）、修尔（阿修的**进化体**） |
   | `mu` | 阿瑞 | 0.8891 | 馋瑞瑞 / 小蛮王（他人绿色系） |
   | `shui` | 小天 | 0.9355 | 帅天天（另一只独立蓝白兽）、人形泳装皮肤（蓝白巧合） |

3. 再用**官方进化原文**交叉验证（第 3 节那张表的最后一列）：五只全部能在官方页面上找到
   「初始形态 → 五王」的进化说明，没有一只靠猜。
4. 你本人对暗王的叫法（**阿修**）与 Top-1 独立吻合 —— 这也是一个旁证。

## 5. 诚实标注：哪些是官方，哪些是推断

| 内容 | 来源性质 |
|---|---|
| 传说五王名单（龙炎/诺亚/帝释天/修尔/阿瑞斯） | **官方原文**（「极」的成长故事 + 精灵大全条目标题） |
| 五只初始形态名（小炎/小诺/小天/阿修/阿瑞） | **官方条目名**，「初始形态 → 五王」有官方进化原文 |
| 「你的 sprite 就是这五只初始形态」 | **推断**（特征比对 Top-1 + 进化学链条 + 用户称呼吻合），对照图见 `names-compare.png` |
| 属性（火 / 超能 / 光 / 恶魔 / 草） | **半推断**：页游详情页的属性栏是脚本渲染、抓不到纯文本；以官方卡面角标为准，**只有小炎存疑**（卡面角标是「战神/平衡」，按技能判为火系） |
| 你的 sprite 的**像素来源** | **不是页游原始像素**：页游这五只初始形态最高清透明图只有 **104×102**，你的帧更精细且带柔和投影 —— 判断为同设计的高清重绘/放大版（手游来源已排除，未采信） |
| 诺雅是诺亚的妹妹、不属于五王 | **官方设定** |
